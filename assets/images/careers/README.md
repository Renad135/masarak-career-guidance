# Career Images Directory

This directory should contain images for each major/career field.

- medicine.jpg - Image representing Medicine field
- computer-science.jpg - Image representing Computer Science
- nursing.jpg - Image representing Nursing
- dentistry.jpg - Image representing Dentistry
- civil-engineering.jpg - Image representing Civil Engineering

## Image Specifications:

- Recommended size: 800x600px or similar aspect ratio
- Format: JPG or PNG
- Quality: High resolution, professional images
- Content: Should represent the field/career visually
